줄바꿈 제거·공백 정리

PDF나 웹에서 복사한 글은 줄 앞뒤에 공백이 많고 빈 줄이 여러 번 들어가는 경우가 많습니다. 이 도구는 줄마다 앞뒤 공백을 지우고, 연속된 빈 줄은 하나로 줄이며, 글 맨 앞과 뒤의 빈 줄도 없앱니다.

줄바꿈 제거가 필요하면 "줄바꿈을 없애고 한 줄로 합치기"를 켜세요. 줄바꿈이 모두 사라지고 줄 사이는 공백 하나로 이어집니다. 단어 사이의 공백은 바꾸지 않습니다.

정리 결과

사용 방법

  1. 정리할 글을 입력 칸에 붙여 넣습니다.
  2. 필요하면 "줄바꿈을 없애고 한 줄로 합치기"를 켭니다.
  3. 결과 칸의 글을 복사해 사용합니다.

계산·처리 방식

각 줄의 앞뒤 공백(스페이스, 탭)을 지웁니다. 빈 줄이 연달아 나오면 하나로 줄이고, 글 맨 앞과 맨 뒤의 빈 줄은 없앱니다. 줄 안에서 단어 사이의 공백은 그대로 둡니다. Windows와 Mac, Linux의 줄바꿈 방식이 섞여 있어도 하나로 통일해 처리합니다.

합치기 옵션을 켜면 앞뒤 공백을 지운 뒤 빈 줄을 버리고, 남은 줄을 공백 하나로 이어 붙여 한 줄로 만듭니다.

예시

" 안녕하세요 " 다음에 빈 줄이 세 줄 있고 " 반갑습니다 "가 이어지는 글을 넣으면, 앞뒤 공백이 지워지고 빈 줄이 하나로 줄어서 "안녕하세요", 빈 줄 하나, "반갑습니다" 순서로 정리됩니다.

합치기 옵션을 켜고 "가나", "다라", 빈 줄, "마바"를 넣으면 "가나 다라 마바" 한 줄이 됩니다.

알아 두세요

  • 문단을 구분하는 빈 줄 하나는 남깁니다. 빈 줄을 모두 없애는 도구는 아닙니다.
  • 줄바꿈 제거 옵션은 줄 사이를 공백 하나로 이어 붙입니다. 한글 문장이 줄 중간에서 끊긴 PDF 글을 합치면 단어 사이에 공백이 생길 수 있으니 결과를 확인하세요.
  • PDF나 웹에서 복사한 글의 불필요한 공백을 정리할 때 알맞습니다.

자주 묻는 질문

단어 사이 공백도 지워지나요?

아닙니다. 줄 시작과 끝의 공백만 지웁니다.

줄바꿈이나 빈 줄을 모두 없앨 수 있나요?

네. "줄바꿈을 없애고 한 줄로 합치기"를 켜면 빈 줄과 줄바꿈이 모두 사라지고 줄 사이가 공백 하나로 이어진 한 줄이 됩니다. 켜지 않으면 문단을 나누는 빈 줄 하나는 남깁니다.

입력한 글이 저장되나요?

저장되지 않습니다. 모든 처리는 브라우저 안에서 이뤄집니다.
