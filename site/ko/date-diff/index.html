날짜 차이 계산기

두 날짜 사이가 며칠인지, 몇 주 며칠인지 계산합니다. 디데이 계산, 계약 기간, 휴가 일수를 셀 때 편하게 쓸 수 있습니다.

종료일을 시작일보다 앞선 날짜로 넣으면 결과 대신 안내 문구가 나옵니다.

일수
주수

종료 날짜가 시작 날짜보다 앞서 있습니다.

올바른 날짜를 입력해 주세요.

사용 방법

  1. 시작 날짜를 선택합니다.
  2. 종료 날짜를 선택합니다.
  3. 일수와 주수 결과를 확인합니다.

계산·처리 방식

두 날짜를 같은 기준 시각(UTC 자정)으로 맞춘 뒤 차이를 하루(24시간) 단위로 나눕니다. 시간대나 서머타임의 영향 없이 날짜 수만 셉니다.

주수는 총 일수를 7로 나눈 몫이고, 남는 일수는 나머지입니다. 윤년은 실제 달력을 기준으로 자동 반영되어 2월 29일이 있는 해도 정확합니다.

예시

2024년 2월 28일부터 3월 1일까지는 2024년이 윤년이라 2월 29일이 있어서 2일입니다.

2025년 1월 1일부터 1월 18일까지는 17일이며, 2주 3일에 해당합니다.

알아 두세요

  • 이 계산기는 종료일에서 시작일을 뺀 값을 보여 줍니다. 시작일과 종료일을 모두 세는 포함 계산이 필요하면 결과에 1을 더하세요. 예를 들어 1월 1일부터 1월 3일까지 모두 세면 3일입니다.
  • 디데이(남은 날) 계산은 시작 날짜에 오늘 날짜를, 종료 날짜에 목표일을 넣으면 됩니다.
  • 종료 날짜가 시작 날짜보다 앞서면 결과 대신 안내 문구가 나옵니다.

자주 묻는 질문

시작일과 종료일이 모두 포함되나요?

포함되지 않습니다. 종료일에서 시작일을 뺀 날짜 수를 보여 드립니다.

윤년도 계산되나요?

네. 2월 29일이 있는 해도 실제 달력을 기준으로 계산합니다.

몇 주 며칠은 어떻게 나오나요?

총 일수를 7로 나눈 몫이 주수, 나머지가 남은 일수입니다.

최종 수정일: 2026-10-19

입력하신 값은 저장되거나 서버로 전송되지 않습니다. 광고 서비스는 쿠키를 사용할 수 있습니다.
